# 介護施設 空き状況検索 MVP

上尾・東大宮周辺の「特別養護老人ホーム」「介護付有料老人ホーム」を、空室・待機人数・月額費用・距離・要介護度などで比較するための静的MVPです。

## 使い方

`index.html` をブラウザで開くか、ローカルサーバーで配信してください。

```bash
python3 -m http.server 8080
```

その後 `http://localhost:8080` を開きます。

## 現在の状態

- データは **すべてデモデータ** です。
- 施設名もデモ用です。
- 実運用では `data.js` を、自治体・厚労省・各施設公式情報から生成するDB/APIへ置き換える想定です。
- Google Maps等のAPIキーは未使用で、地図は簡易表示です。

## 次の実装候補

1. 埼玉県の特養空床・待機情報を取り込む
2. 介護サービス情報公表システムの施設マスタを取り込む
3. 各介護付有料老人ホームの公式空室情報を取り込む
4. Supabaseへ施設・更新履歴を保存
5. 公式Google Mapsへ置換
