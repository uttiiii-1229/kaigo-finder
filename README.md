# 上尾市 介護施設 空き情報

公開サイトは上尾市内の特別養護老人ホーム12施設、介護付有料老人ホーム9施設を一覧表示します。施設マスタと時点情報は `data/facilities.json` に保存しています。自動更新ではありません。

- 特養：埼玉県の県央圏域PDF（2026年9月1日集計、資料内の情報更新日8月24日）。非掲載欄は `null` で表現し、0と区別します。PDFの空床・待機は任意回答です。
- 介護付有料：上尾市の住所地特例施設一覧表。空室情報は運営者の公式ページに数値・状態の掲載がある施設のみです。各レコードの `statusSource` と `statusDate` を参照してください。
- 月額費用、東大宮駅からの距離、個別の受け入れ可否は未収録です。

データを更新するときは各出典を確認し、`data/facilities.json` の数値・基準日・出典URL・最上位の `version` を同時に更新します。GitHubの main ブランチに反映すると、接続済みVercelプロジェクトに自動デプロイされます。

ローカルで見る場合：`python3 -m http.server 8080` を実行し、`http://localhost:8080` を開きます。
